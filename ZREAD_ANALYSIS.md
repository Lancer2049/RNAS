## Overview

RNAS (RADIUS Network Access Server) is a standalone NAS simulation platform for x86 Linux. It deep-integrates accel-ppp with standard Linux networking services (dnsmasq, nftables, tc, strongSwan, keepalived) under a single unified configuration tree at `/etc/rnas/`, fronted by a web dashboard and a FastAPI management API.

Unlike OpenWrt-based NAS solutions, RNAS requires no firmware flashing: it installs on any Debian/Ubuntu/UOS x86_64 host or VM via a one-command installer and runs entirely under systemd.

### What RNAS Solves

Testing RADIUS authentication, accounting, and CoA (Change of Authorization) against real access protocols normally requires commercial BRAS hardware or a complex multi-package setup on OpenWrt. RNAS collapses this into a single installable platform: one config tree feeds twelve native config generators, five access protocols run simultaneously through accel-ppp, and a Vue.js dashboard provides real-time session visibility.

RNAS is built on the **"fusion, not aggregation"** principle: accel-ppp and Linux services share one config tree rather than being packaged side-by-side.

## Design Principles

| Principle | What It Means | Implementation |
|-----------|---------------|----------------|
| **Fusion, not aggregation** | accel-ppp and Linux services share one config tree | Single `/etc/rnas/` root |
| **One config tree** | UCI-style INI config for all services | `rnas-config` parser via `rglob("*.conf")` |
| **systemd native** | Services use systemd units, not procd | 9 service files + `rnas.target` |
| **Installable, not flashable** | Any x86 Linux, no firmware needed | `bash scripts/install.sh` |
